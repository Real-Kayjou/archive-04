Privacy / Data Control

Last updated: October 11, 2026

What is stored

This portfolio stores public project entries and, for the owner’s admin account, an email address and an authentication session managed by Supabase. Project titles, descriptions, links, status, tools, and optional images may be stored when the owner adds an exhibit.

Browser storage and services

The site uses browser storage for interface preferences and local project fallback data. Supabase provides authentication and the project database. Google Fonts and hosted Three.js assets may receive normal browser request data such as your IP address and user agent. No advertising or tracking profile is intentionally created.

Admin access

Only the portfolio owner’s authenticated Supabase account is intended to manage projects. Public visitors can view published projects but cannot add or delete them. Database row-level security is the actual access control; hiding controls in the interface is not relied upon for security.

Your requests

To ask about your data, request deletion, or report a privacy issue, email saiftig450@gmail.com. Include enough detail to identify the request. Deletion requests are handled manually by the site owner.

Not legal advice

This page is a plain-language portfolio notice, not a substitute for legal advice. Update it with your legal name, business details, jurisdiction, retention period, and any additional services before operating commercially or collecting information beyond the admin account.
